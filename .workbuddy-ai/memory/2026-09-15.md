## Search select untuk semua dropdown data banyak
Tujuan: setiap select yang isinya bisa panjang (mahasiswa, dosen, mata kuliah, kelas, ruangan, CPMK, wilayah) wajib bisa dicari.
- `components/ui/SearchSelect.vue` **ditulis ulang**: combobox lengkap (kotak cari, navigasi keyboard ↑↓/Home/End/Enter/Esc, `activeIndex`, penanda terpilih, tombol kosongkan, badge, `loading`). Panel dropdown di-**Teleport ke body** dengan posisi `fixed` (`z-index: 120`, app pakai `z-50` untuk modal) supaya tidak terpotong `overflow` di dalam modal. `sameValue()` membandingkan longgar (`String(a)===String(b)`) sehingga `"7"` dari URL cocok dengan id numerik `7`.
- `components/ui/Select.vue` **jadi pintar**: tetap `<select>` bawaan untuk daftar pendek, otomatis jadi SearchSelect bila jumlah opsi > `searchThreshold` (default 8). Prop baru: `searchable` (paksa on/off), `searchThreshold`, `searchPlaceholder`.
- **Kunci cakupan**: 43 dari 85 pemakaian `<Select>` menaruh opsi sebagai anak `<option>` (slot), bukan lewat `:options`. `Select.vue` membaca vnode slot itu (`readSlotOptions()` — rekursif lewat Fragment/Text/Comment, ambil `props.value` + teks) sehingga semua halaman lama ikut searchable **tanpa perlu mengedit satu per satu**. Fungsi dipanggil dari template (saat render), bukan `computed`, agar isi slot tetap segar saat data selesai dimuat; bila parsing gagal → fallback ke `<select>` bawaan (perilaku lama).
- Native `<select>` data besar yang dikonversi ke `<Select>` + options computed: `advising/Index.vue` & `enrollments/Index.vue` (dosen wali), `exams/Index.vue` (ruang ujian, dosen pengawas), `curriculum/study-programs/Show.vue` (mata kuliah), `outcomes/cpmk/Create.vue` (mata kuliah), `outcomes/sub-cpmk/Create.vue` + `outcomes/sub-cpmk/Index.vue` (CPMK).
- Daftar kecil (prodi, semester, periode, tahun, fakultas, kampus, gedung, jenis/kelompok MK, status, gender, agama) sengaja tetap `<select>` bawaan — lebih baik untuk keyboard/mobile.
- Catatan perilaku: SearchSelect memancarkan nilai bertipe asli (number), sedangkan jalur `<select>` bawaan tetap string seperti sebelumnya.
- Test baru `src/__tests__/search-select.spec.ts` (11 test) untuk ambang, opsi dari slot, filter, nilai bertipe, tombol kosongkan, dan navigasi keyboard.
- Logika pembacaan vnode dipisah ke `src/components/ui/slotOptions.ts` (`readSlotOptions`, `vnodeText`) agar bisa diuji tanpa Vite.
- Verifikasi tanpa vitest: `node --experimental-strip-types verify-slot-options.mts` (dari folder `frontend`) — 19/19 lulus. Skrip ini menemukan **bug nyata**: `<option :value="null">` ikut berubah jadi `''` karena `props.value ?? ''`; sudah diperbaiki dengan cek `'value' in vnode.props`.

## Jebakan environment
- `vitest` dan Vite SSR (`ssrLoadModule`) **menggantung** di sandbox ini (worker spawn / transport invoke timeout 60s). Alternatif yang berhasil: uji logika murni dengan `node --experimental-strip-types` + vnode asli dari `h()`.
- Menjalankan `vue-tsc` dan `vitest` **bersamaan** membuat load average melonjak >90 dan keduanya menggantung tanpa output. Jalankan satu per satu.
- `pkill -f "vue-tsc"` membunuh shell-nya sendiri; pakai pola bracket `pkill -f "vue[-]tsc"`.
- `grep --include=...` tidak dapat diandalkan di shell sandbox ini — pakai tool Grep bawaan.
- `timeout` tidak tersedia di macOS.
